# Fiche de demande — entrée OmniBrain

> Copier ce fichier, le remplir, puis : `omnibrain plan task-intake.md -o plan.md`

## 1. Demande (une phrase, verbe d'action)

_Que faut-il accomplir ? Pour qui ?_

## 2. Contexte

_Périmètre, système existant, contraintes (juridiction, délai, budget, stack)._

## 3. Résultat attendu

_Livrable concret considéré comme « terminé ». Critères observables._

## 4. Contraintes et hors-périmètre

_Ce qui ne doit PAS être touché, les dépendances, les interdits._

## 5. Sources ou références éventuelles

_Liens, documents, textes applicables (avec dates)._
